# Rumbo UI design conventions

Design rules for the Rumbo interface (`frontend/src/vistas/`, primitives in
`frontend/src/vistas/primitivos.ts`). Every change to tables, marks and time controls MUST
follow them. Number, currency and date rendering rules live in
[UI_FORMATTING.mdx](./UI_FORMATTING.mdx); this document covers the design layer on top.

The rules are written as a template: they describe how the interface behaves, not a
particular deployment or company.

## 1. Tables

### 1.1 Uniform units go in the header

If the same unit repeats across the rows of a column, it moves to the column header and the
cells carry bare numbers:

| Without hoisting   | With hoisting          |
| ------------------ | ---------------------- |
| **Concedido**      | **Concedido (k€)**     |
| 160 k€             | 160                    |
| 0 €                | 0                      |
| 95 k€              | 95                     |

- The unit suffix in the header keeps the UI_FORMATTING form: `Concedido (k€)`,
  `Interés (%)` — with a non-breaking space inside the unit (`k€`, `%`), never inside the
  parentheses.
- **Zero is unit-agnostic** (`0 € = 0 k€ = 0 M€`): a zero cell never prevents hoisting, and
  under a hoisted unit it renders as `0`.
- **Mixed units stay per-row.** If a column genuinely mixes `€` and `k€` values (or a value
  is missing, rendered `—`), the header stays unit-less and each cell keeps its own
  formatted suffix, as before.
- Percentages follow the same rule: a column where every cell is a percent hoists `%` to the
  header and the cells show the bare number.
- **Marks hoist the same way.** A symbol repeated in every row of a column (the bank logo,
  §2) rises to the column header once; the cells keep only their text. If the values differ,
  each cell keeps its own mark. Filtering the column down to a single entity moves its mark
  up on its own.
- Reference implementation: the *Otras deudas* table in `frontend/src/vistas/ficha.ts`
  (unit detection + `f.eurosEn` in `frontend/src/datos/formato.ts`; `bancoComun` + `marcaBanco`
  for the hoisted entity mark).

### 1.2 Category filter above the table

When a table's first column repeats a small set of categories (the *Tipo* column of
*Otras deudas*: Préstamo, Aval, …), the section exposes a pill filter row between the
title and the table:

- Buttons `button.filtro-opcion` inside a `role="group"` with a Spanish `aria-label`;
  state via `aria-pressed`, first pill is *Todos*.
- The filter only renders when there is more than one distinct category.
- Filtering re-renders the table and **re-measures the hoisted units on the visible
  rows**: a filter can change the common unit of a column (§1.1).
- Reference implementation: *Otras deudas* in `frontend/src/vistas/ficha.ts`.

### 1.3 Sortable headers

Wide entity tables (the fleet of companies of a group) expose sortable columns through the
shared primitive `cabecerasOrdenables` in `frontend/src/vistas/primitivos.ts`:

- Every header cell is a real `<button>` inside the `<th>`, with `aria-sort` on the `th` and
  a small arrow (↑/↓) next to the label.
- Clicking toggles: first click ascending, second click descending, on the same column.
- Missing values (`null` → `—`) always sort last, in both directions.
- Numbers compare numerically; text compares with Spanish collation (`es`, numeric mode), so
  `Empresa 8` precedes `Empresa 23`.
- Reordering reuses the existing `<tr>` nodes: row listeners and focus survive a sort.
- A table may declare an initial sort (the fleet table starts score-ascending, worst first).

## 2. Entity marks (banks and counterparties)

Every time a bank or counterparty is named — a table cell, a contract line — the name opens
with its **real logo**:

- `marcaBanco(nombre)` in `frontend/src/vistas/primitivos.ts` resolves the entity to a
  vendored logo via `logoBanco()` (`frontend/src/vistas/logos.ts`), matched by normalized
  name keywords (accents stripped, product suffixes like "Empresas" or "Net Cash" ignored).
- Logos are **local data-URIs** committed in `logos.ts` (sourced from the Google favicon
  service and Simple Icons): no third-party request ever happens at runtime or in the build.
  The trademarks belong to their owners; they only identify the bank of each product.
- **Fallback**: an entity without a vendored logo (unknown bank, "In-house bank", "Other")
  renders the engraved typographic monogram — double-ring disc, initials of the significant
  words, current ink (`--tinta`). Anonymous entities (`—`) render no mark.
- **A repeated symbol hoists to the header** (§1.1): when every visible row of a column is
  the same entity, the logo rises once to the column header and the cells keep only the name;
  when the entities differ, each cell carries its own mark. A filter that narrows a column to
  a single bank moves the logo up.
- Size is 20 px in tables; `alt=""` because the entity name is always text next to it.
- Reference implementation: the *Entidad* column of *Otras deudas* (`marcaBanco` + `bancoComun`)
  and the contract lines (`contratos`) in `frontend/src/vistas/ficha.ts`.

## 3. Time ruler and playback controls

The time ruler (`div.regla` in `frontend/src/vistas/regla.ts`) is a control, not decoration:
it selects the interval every screen reads.

- It renders wherever the selected interval changes the reading: portfolio (plano, tapiz),
  and the **Scoring tab** of an organization or company.
- On an organization or company it is **hidden on every tab but Scoring** (productos,
  acciones, técnico): the window selector belongs to the screen that reads it, and a
  ruler elsewhere suggests a filtering that does not exist.
- The playback (`reproducir`) and window-mode (`modo`) controls belong to the ruler and hide
  with it.

## 4. Quick reference

| Case                              | Rule                                            |
| --------------------------------- | ----------------------------------------------- |
| Unit repeated in every row        | Hoist to header: `Concedido (k€)`, bare cells   |
| Column mixes € and k€             | Keep per-row suffixes, plain header             |
| Zero under a hoisted unit         | Render `0` (unit-agnostic)                      |
| Missing value                     | `—`, sorts last in sortable tables              |
| Same entity in every row          | Logo hoists to the header, cells keep the name |
| Bank or counterparty row          | Real logo (vendored locally) + name; monogram fallback |
| Comparative data (`cifraC` tono)  | `baja` in red (`--peligro-t`), `sube` in green (`--exito-t`), value and comparison |
| Entity pages                      | Time ruler only on the Scoring tab; no playback elsewhere |
